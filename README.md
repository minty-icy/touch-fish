# Diet Tracker

A lightweight, single-page diet tracking dashboard. Log meals, monitor macros, and keep hydration targets in sync with your personal goals—all stored locally in your browser.

## Features
- Quick logging for calories, protein, carbs, fats, and water per meal
- Daily goals with smooth scrolling shortcuts to adjust targets or add meals
- Auto-calculated daily totals, goal progress bars, and a week-at-a-glance history
- Local storage persistence so your entries stay on this device

## Getting started
1. Open `index.html` in your browser.
2. Set your daily goals (calories, macros, water) and save them.
3. Select a date, log meals, and view summaries plus recent history.

Everything runs client-side—no build steps needed.
