# TouchFish Wellness Tracker

A lightweight, single-page dashboard to track weight trends, calories, and water — with a focus on clean visuals and no macro counting.

## Features
- Add daily weight entries (in pounds) with a responsive line graph (powered by Chart.js) and quick highlights for best/worst changes.
- Log individual food items with their calories alongside daily water entries, plus a quick-add prompt for fast capture.
- Dashboard stats for latest weight, today’s calories, today’s hydration, and 7-day averages.
- Local storage persistence, so your entries stay available without any backend setup.

## Usage
Open `index.html` in your browser. Entries are stored in `localStorage`; no build tools or servers are required.
